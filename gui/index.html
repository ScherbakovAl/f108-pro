Click a key to paint it; click again with the same color to clear it.
Base color black (#000000) means "no base": only painted keys are sent.

Each apply replaces the whole remap table on the selected layer.

A preset stores the checked sections as they are set in the other tabs. Applying a preset loads it into the tabs and sends it to the keyboard. A remap section with no rows restores that layer to defaults.
